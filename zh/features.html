功能总览

TexForge 把美术资源流程中重复、易错、需要脚本的环节，做成了可配置、可复用、可校验的桌面工具。

批处理动作（113 个）

尺寸与画布：缩放、裁剪、旋转、翻转、内边距、画布扩展、锚点对齐。先把几何定下来，后续动作的开销才好估算。

画质与格式：重采样、锐化、量化、位深、PNG / JPEG / WebP / TGA / DDS 转换，以及按目标体积压缩。

内容加工：水印、边框、圆角、蒙版、色彩调整与 ICC 色彩空间转换。

文件与元数据：批量重命名、目录结构规划、EXIF / XMP / IPTC 读写与清理。

执行模型：动作按添加顺序叠加，前一个的输出是后一个的输入；单张失败不中断整批，失败项写入报告，修好后只重跑失败项。

深入阅读：批量图像处理实战：一次配置，处理上千张图 →

纹理图集打包（69 种格式）

排布策略：按尺寸、按名称、按分组；支持留白（padding）、边缘扩展（extrude）、旋转与透明边界裁剪（trim）。

输出格式：Unity、Godot、Unreal、Cocos2d、Phaser 2/3、PixiJS、Spine、LibGDX、SpriteKit、Starling、Egret、LayaAir、微信小游戏，以及通用 JSON / XML / plist / CSS / CSV。

约束校验：POT / NPOT、最大尺寸、留白一致性、空区域检测，导出前就能发现踩线项。

图集图片与描述文件同名同目录生成，复制进项目即可被引擎识别，不再手改坐标。

深入阅读：纹理图集打包完全指南：留白、裁剪、2 的幂与 69 种格式 →

引擎数据导出（24 种格式）

覆盖 Unity、Unreal、Godot、Cocos 与自定义模板五类目录树规划，按引擎习惯落地到 Assets / Content 等目标目录。

JSON、XML、plist、CSS、CSV、SpriteSheet 与引擎专用元数据都能一次导出。

自定义模板适合自研引擎或内部规范，字段与嵌套结构可裁剪。

同一份图集可并行导出多个引擎版本，避免为不同平台重复打包。

深入阅读：24 种引擎数据格式：Unity、Godot、Unreal、Cocos 一次导出 →

法线贴图与通道打包

从高度图生成法线贴图，强度可调，Y 轴方向支持 OpenGL / DirectX 两种约定切换。

按 ORM、RMA 等约定把粗糙度、金属度、AO 打包进 RGB 通道，替代逐张手工拼通道。

通道顺序可配置，适配 Unity 与 Unreal 的不同读取习惯。

法线贴图始终按线性数据处理，避免被 sRGB 管线二次校正。

深入阅读：法线贴图与通道打包：ORM、粗糙度、金属度的正确做法 →

Mipmap 与平台尺寸校验

按 2 的幂生成 Mipmap 链，可选重采样滤镜、是否保留 Alpha。

内置移动端与桌面端的尺寸上限校验，超限纹理在导出前被标记，而不是等引擎报错。

适合同时出多平台包的团队：一份源图，多套目标规格，减少上线前返工。

深入阅读：Mipmap 与平台尺寸限制：移动端纹理不再踩坑 →

精灵切图与九宫格

从整张精灵表按网格或透明间隔拆分，输出独立小图与命名序号。

九宫格切图按边框像素拆分四角与四边，适配 UI 拉伸需求。

拆分后可继续叠加批处理动作，或直接进入图集打包流程。

深入阅读：精灵表与九宫格：移动 UI 切图的正确姿势 →

元数据与命名规范

EXIF / XMP / IPTC 的读取、写入与清理，支持按规则批量改写描述、作者、版权字段。

重命名支持前缀、后缀、序号、原文件名变量与目录结构规划。

发布前可一键剥离隐私字段，同时补写版权与来源信息。

深入阅读：EXIF / XMP / IPTC 工作流：版权、作者与批量清理 →

资产审查与报告

扫描命名规范、尺寸一致性、重复文件、法线 / 颜色配对缺失等问题。

输出 CSV / JSON 报告，可作为 CI 门禁、美术验收依据或版本发布记录。

支持按平台尺寸规格（如移动端 POT 上限）做批量判定。

报告与预设可以一起进版本库，成为资源规范的一部分。
