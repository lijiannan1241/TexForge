功能总览

TexForge 把美术资源流程中重复、易错、需要脚本的环节，做成了可配置、可复用、可校验的桌面工具。

批处理动作（113 个）

尺寸与画布：缩放、裁剪、旋转、翻转、内边距、画布扩展、锚点对齐。

画质与格式：重采样、锐化、格式转换、量化、压缩与目标体积控制。

内容加工：水印、边框、圆角、蒙版、色彩调整与 ICC 转换。

文件与元数据：重命名、目录结构、EXIF / XMP / IPTC 读写与清理。

所有动作按顺序叠加执行，单张失败不会中断整批，失败项会在报告中列出并可重跑。

纹理图集（69 种格式）

排布策略：按尺寸、按名称、按分组，支持留白、边缘扩展（extrude）、旋转与裁剪（trim）。

输出格式：Unity、Godot、Unreal、Cocos2d、Phaser 2/3、PixiJS、Spine、LibGDX、SpriteKit、Starling、Egret、LayaAir、微信小游戏，以及通用 JSON / XML / plist / CSS / CSV。

约束校验：POT / NPOT、最大尺寸、留白一致性、空区域检测，导出前即可发现踩线项。

引擎数据格式（24 种）

覆盖 Unity、Unreal、Godot、Cocos 与自定义模板五类目录树规划。

图集描述文件与图片同名同目录生成，直接复制进项目即可被引擎识别。

自定义模板适合自研引擎或内部规范，字段可裁剪。

法线贴图与通道打包

从高度图生成法线贴图，支持强度与 Y 轴方向（OpenGL / DirectX）切换。

按 ORM、RMA 等约定把粗糙度、金属度、AO 打包进 RGB 通道，避免逐张手工作业。

通道顺序可配置，适配 Unity 与 Unreal 的不同习惯。

Mipmap 与平台限制

按 2 的幂生成 Mipmap 链，可选滤镜与是否保留 Alpha。

内置移动端与桌面端的尺寸上限校验，超限纹理在导出前被标记。

适合需要同时出多平台包的团队，减少上线前的返工。

资产审查与报告

扫描命名规范、尺寸一致性、重复文件、法线/颜色配对缺失等问题。

输出 CSV / JSON 报告，可作为 CI 门禁或美术验收依据。

支持按平台尺寸规格（如移动端 POT 上限）做批量判定。
