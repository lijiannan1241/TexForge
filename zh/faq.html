隐私说明

TexForge 完全在本机运行，不收集、不上传任何个人信息与图片内容；不包含遥测、广告或第三方追踪 SDK。

产品与定位

TexForge 是什么？

TexForge 是一款 Windows 桌面工具，把批量图像处理与纹理图集打包放在同一套管线里。它同时提供图形界面和命令行，适合独立开发者、美术和技术美术在日常资源生产中使用。

和 Photoshop 动作、ImageMagick 脚本有什么区别？

Photoshop 动作绑定在单一软件里，ImageMagick 需要自己拼命令行。TexForge 把动作序列、图集参数与引擎导出做成可视配置，可保存为预设，并由 GUI 与 CLI 共用；同时内置图集描述文件与引擎目录规划，这部分是通用图像工具不提供的。

适合谁用？

独立开发者、2D / 2.5D 美术、技术美术、外包验收人员，以及需要为多个平台出包的小型团队。

界面支持中文吗？

支持。首次启动可选择中文或 English，之后可在设置里切换，两种语言的界面功能完全一致。

格式与引擎

支持哪些图片格式？

常见位图格式均可读写，包括 PNG、JPEG、WebP、BMP、TIFF、TGA、DDS 等，并可通过扩展编解码器补充能力。

69 种图集格式具体指什么？

指图集描述文件与图片的组合格式，覆盖 Unity、Godot、Unreal、Cocos2d、Phaser 2/3、PixiJS、Spine、LibGDX、SpriteKit、Starling、Egret、LayaAir、微信小游戏，以及通用 JSON / XML / plist / CSS / CSV。

支持哪些游戏引擎？

内置 Unity、Unreal、Godot、Cocos 的目录规划与元数据导出，共 24 种引擎数据格式，并提供自定义模板。

能用自定义引擎模板吗？

可以。模板字段与嵌套结构可裁剪，适合自研引擎或团队内部规范。

支持微信小游戏等 H5 运行时吗？

支持。可导出对应的图集描述与元数据，直接用于微信小游戏、Cocos、Phaser、PixiJS 等运行时。

功能细节

图集打包支持留白、裁剪和 2 的幂吗？

支持。可设置留白与边缘扩展、按透明边界裁剪、旋转小图，并校验 POT / NPOT 与最大尺寸限制。

法线贴图的 Y 轴方向可以切换吗？

可以。在 OpenGL 与 DirectX 两种约定间切换，强度也可调，并且始终按线性数据处理。

Mipmap 与平台尺寸校验怎么用？

按 2 的幂生成 Mipmap 链，并对照移动端与桌面端的尺寸上限做批量校验，超限纹理会在导出前被标记。

能处理多少张图片？

没有硬性张数限制，实际取决于磁盘空间、内存与单张图片尺寸。建议大批量任务先用小样本验证预设，再全量运行。

九宫格与精灵拆分在哪里？

在图集工具箱工作区，可按网格或透明间隔拆分精灵表，也可按边框像素做九宫格切图，输出后可直接进入批处理或图集打包。

安装、许可与隐私

如何获取与更新？

通过 Microsoft Store 安装可获得自动更新。商店页面会显示当前版本与系统要求。

系统要求是什么？

Windows 10 / Windows 11（x64）。大批量任务建议 8 GB 以上内存，磁盘空间取决于处理的图片规模。

需要联网才能用吗？

不需要。安装完成后可离线使用，所有处理都在本地完成。

会收集我的数据吗？

不会。TexForge 完全在本机运行，不上传图片、不回传遥测、不包含广告或追踪 SDK。详见隐私政策。

自动化与支持

图形界面和命令行有什么区别？

两者共用同一套管线与预设。GUI 适合调试与预览，CLI（texforge-cli）适合批处理脚本、构建服务器与 CI 自动化。

能接入 CI 吗？

可以。CLI 可读取与 GUI 相同的预设文件，按退出码判断成败，结果报告可归档为构建产物。
