Download & install

TexForge is available on Microsoft Store. Installing from the Store gives you automatic updates and clean uninstallation.

Get it fromMicrosoft Store
1

Open the store listing

Click any Microsoft Store button on this site, or search for TexForge in the Store.

2

Install

Click Get / Install on the listing and wait for the download to finish.

3

Launch

Start TexForge from the Start menu and choose Chinese or English on first run.

System requirements

  • Windows 10 / Windows 11 (x64)
  • Disk space depends on the size of the image set
  • 8 GB RAM or more recommended for large batches
  • Core features work offline

Command line

The package includes texforge-cli for scripts and CI. The GUI and CLI share the same actions and presets.

texforge-cli --help
