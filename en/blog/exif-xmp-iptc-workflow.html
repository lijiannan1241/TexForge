EXIF / XMP / IPTC workflows: copyright, authorship and bulk cleanup

How to stamp copyright and authorship consistently, strip private fields before publishing, and handle ICC profiles correctly.

Metadata2026-10-21·3 min read

Key takeaways

  • Write metadata in bulk, not file by file
  • Strip GPS and other private fields before publishing
  • ICC profiles decide color consistency

An image carries more than pixels: capture device, time, author, copyright, keywords, color profile. Internally that is searchable provenance; externally it can leak information you never meant to publish.

Why metadata deserves management

Art deliveries often have missing or inconsistent copyright and author fields. The gap only becomes obvious when a third party reposts the work and you cannot prove ownership. Consistent stamping is the cheapest form of protection.

Conversely, phone or camera captures may embed GPS coordinates, device serial numbers and edit history. Those fields should be stripped before public release, not patched afterwards.

Bulk writing and stripping

Editing metadata file by file is not realistic. Batch processing should support writing author, copyright and keywords consistently; appending or overwriting by rule; and keeping a whitelist while removing the rest.

  • Write: author, copyright notice, project name, license type.
  • Remove: GPS, device details, editing history, comments.
  • Keep: color profile, orientation, necessary resolution data.

ICC and color consistency

Devices and applications interpret color through ICC profiles. A missing or wrong profile makes the same image look different on an artist's monitor and a player's device. Batch conversion should define the target color space and embed the matching profile.

A common approach is converting everything to sRGB before delivery to reduce cross-platform drift; print or specialized pipelines may need a wider gamut and separate handling.

Compliance angle

For markets such as the EU, stripping privacy-related metadata is not just best practice but part of compliance. Publicly released images should not unintentionally carry location and device information.

Practical advice

  1. Put metadata rules in the delivery checklist instead of verbal agreements.
  2. Run a cleanup batch before publishing while keeping required copyright fields.
  3. Convert color space and embed the profile together, not one without the other.
  4. Spot-check results with the system properties panel or a metadata viewer.

Takeaway

Metadata is part of the asset, not an accessory. Write consistently, strip thoroughly, keep color traceable. All three are batchable, so there is no reason to do them by hand.
