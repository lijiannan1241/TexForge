One toolkit for the whole art pipeline

From converting a single image to shipping a full atlas into an engine, TexForge turns repetitive work into reusable configuration.

01

113 batch actions

Resize, crop, rotate, sharpen, watermark, convert, compress and edit metadata — stack them, run in order, and get a result report.

02

69 atlas formats

Sprite atlas descriptors for Unity, Godot, Unreal, Cocos, Phaser, PixiJS, Spine, LibGDX, Egret, LayaAir and more.

03

24 engine data formats

Export JSON, XML, plist, CSS, CSV, sprite sheets and engine-specific metadata straight into your project folders.

04

Normal maps & channel packing

Generate normal maps from height maps and pack roughness, metallic and AO with ORM / RMA conventions — no more manual channel mistakes.

05

Mipmaps & platform limits

Build mip chains per platform and validate texture size limits for mobile and desktop before they break a build.

06

Asset audits & reports

Scan naming, dimensions, duplicates and missing pairs in bulk, then export CSV / JSON reports for reviews and CI gates.

Four workspaces for four real jobs

Stop bouncing between a dozen tiny utilities. Enter the workspace that matches the task and finish the loop from source art to shippable output.

Game pixel tools

Normal maps, channel packing, mipmaps and engine folder planning for 2D / 2.5D / 3D assets.

Batch

Apply an action sequence to an entire folder with presets, recursive scanning and retry for failed items.

Atlas toolbox

Nine-patch slicing, sprite splitting, size and naming validation, and other supporting utilities.

Atlas

Layout, padding, trimming, rotation and multi-format export — atlas image and descriptor generated together.

Three steps to a release-ready batch

1

Import

Drop in folders or images, scan subdirectories recursively, filter by extension and naming rules.

2

Configure

Stack actions or tune atlas parameters, save them as a preset and reuse it next time.

3

Export

Write to the target folder, generate atlases plus engine metadata, and get a verifiable result report.
