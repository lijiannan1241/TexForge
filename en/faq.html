Frequently asked questions

Common questions about features, formats, engine support, privacy and installation.

Privacy

TexForge runs entirely on your machine. It does not collect or upload personal information or image content, and contains no telemetry, advertising or third-party tracking SDKs.

What is TexForge?

TexForge is a Windows desktop tool that puts batch image processing and texture atlas packing into one pipeline. It ships both a GUI and a CLI, aimed at indie developers, artists and technical artists.

Which image formats are supported?

Common raster formats can be read and written, including PNG, JPEG, WebP, BMP, TIFF, TGA and DDS, with optional extended codecs. The atlas side supports 69 descriptor formats.

Which game engines are supported?

Built-in folder planning and metadata export for Unity, Unreal, Godot and Cocos — 24 engine data formats in total — plus Phaser, PixiJS, Spine, LibGDX, SpriteKit, Egret, LayaAir and custom templates.

Does it collect my data?

No. TexForge runs entirely on your machine. It does not upload images, send telemetry, or include advertising or tracking SDKs. See the privacy policy for details.

Does it need an internet connection?

No. After installation it works offline; all processing happens locally.

What is the difference between the GUI and the CLI?

They share the same pipeline and presets. The GUI is for tuning and previewing; the CLI (texforge-cli) is for batch scripts, build servers and CI automation.

Does atlas packing support padding, trimming and power-of-two?

Yes. You can set padding and edge extrusion, trim by alpha bounds, rotate small sprites, and validate POT / NPOT and maximum size limits.

How many images can it process?

There is no hard limit; throughput depends on disk space, memory and image dimensions. For large jobs, validate the preset on a small sample first.

How do I install and update?

Install from Microsoft Store to receive automatic updates. The store listing shows the current version and system requirements.

How do I report a problem?

Email cdljn2022@gmail.com or open an issue on the GitHub repository. Include the version, steps to reproduce and the result report to speed things up.
