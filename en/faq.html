Privacy

TexForge runs entirely on your machine. It does not collect or upload personal information or image content, and contains no telemetry, advertising or third-party tracking SDKs.

Product basics

What is TexForge?

TexForge is a Windows desktop tool that puts batch image processing and texture atlas packing into one pipeline. It ships both a GUI and a CLI, aimed at indie developers, artists and technical artists.

How is it different from Photoshop actions or ImageMagick scripts?

Photoshop actions live inside one application and ImageMagick means hand-assembling command lines. TexForge makes action sequences, atlas parameters and engine exports configurable, saves them as presets shared by GUI and CLI, and ships atlas descriptors and engine folder planning that generic image tools do not provide.

Who is it for?

Indie developers, 2D / 2.5D artists, technical artists, outsourcing reviewers and small teams shipping to several platforms.

Is the UI available in Chinese?

Yes. Pick Chinese or English on first run and switch later in settings; both interfaces expose the same features.

Formats and engines

Which image formats are supported?

Common raster formats can be read and written, including PNG, JPEG, WebP, BMP, TIFF, TGA and DDS, with optional extended codecs.

What are the 69 atlas formats?

Descriptor-plus-image combinations for Unity, Godot, Unreal, Cocos2d, Phaser 2/3, PixiJS, Spine, LibGDX, SpriteKit, Starling, Egret, LayaAir and WeChat mini games, plus generic JSON / XML / plist / CSS / CSV.

Which game engines are supported?

Built-in folder planning and metadata export for Unity, Unreal, Godot and Cocos — 24 engine data formats in total — with custom templates for anything else.

Can I use custom engine templates?

Yes. Fields and nesting can be trimmed to fit in-house engines and internal conventions.

Does it support HTML5 runtimes such as WeChat mini games?

Yes. Atlas descriptors and metadata export directly for WeChat mini games, Cocos, Phaser and PixiJS runtimes.

Capability details

Does atlas packing support padding, trimming and power-of-two?

Yes. Set padding and edge extrusion, trim by alpha bounds, rotate small sprites, and validate POT / NPOT and maximum size limits.

Can the normal map Y axis be switched?

Yes. Switch between OpenGL and DirectX conventions, adjust strength, and keep normal maps on the linear data path.

How do mipmaps and platform size checks work?

Power-of-two mip chains are generated, then validated against mobile and desktop size limits; oversized textures are flagged before export.

How many images can it process?

There is no hard limit; throughput depends on disk space, memory and image dimensions. For large jobs, validate the preset on a small sample first.

Where are nine-patch and sprite splitting?

In the Atlas toolbox workspace: split sprite sheets by grid or transparent gutters, or slice nine-patch borders, then feed the output into batch actions or the atlas packer.

Install, licence and privacy

How do I install and update?

Install from Microsoft Store to receive automatic updates. The store listing shows the current version and system requirements.

What are the system requirements?

Windows 10 / Windows 11 (x64). 8 GB RAM or more is recommended for large batches; disk space depends on the image set.

Does it need an internet connection?

No. After installation it works offline; all processing happens locally.

Does it collect my data?

No. TexForge runs entirely on your machine. It does not upload images, send telemetry, or include advertising or tracking SDKs. See the privacy policy for details.

Automation and support

What is the difference between the GUI and the CLI?

They share the same pipeline and presets. The GUI is for tuning and previewing; the CLI (texforge-cli) is for batch scripts, build servers and CI automation.

Can it run in CI?

Yes. The CLI reads the same preset files as the GUI, reports success through exit codes, and writes result reports you can archive as build artifacts.
