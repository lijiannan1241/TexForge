Transcript

Intro: TexForge is a Windows tool for batch image processing and texture atlas packing, with a Chinese and English UI, running entirely on your machine.

Batch: drop in a folder, stack any combination of 113 actions and save them as a preset. Run it, then review progress, failed items and the result report — retry only the failures.

Atlas: set padding, edge extrusion, trimming and rotation, choose a target format. Export writes the atlas image and descriptor together, across 69 formats including Unity, Godot, Unreal and Cocos.

Game pixel tools: generate normal maps from height maps, pack ORM / RMA channels, build mip chains, validate platform size limits and plan the engine folder tree.

Atlas toolbox: nine-patch slicing, sprite sheet splitting, size and naming validation — output feeds straight into batch actions or the atlas packer.

CLI: presets saved in the GUI run unchanged through texforge-cli on a build server, with exit codes and reports that fit a CI pipeline.

Outro: TexForge is available on Microsoft Store for Windows 10 / 11 (x64), and works offline after installation.
