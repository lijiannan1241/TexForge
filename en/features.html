Features

TexForge turns the repetitive, error-prone and script-dependent parts of an art pipeline into configuration you can reuse and verify.

Batch actions (113)

Size and canvas: resize, crop, rotate, flip, padding, canvas expansion, anchor alignment.

Quality and format: resampling, sharpening, format conversion, quantization, compression and target file size.

Content: watermarks, borders, rounded corners, masks, color adjustments and ICC conversion.

Files and metadata: renaming, folder structure, EXIF / XMP / IPTC read, write and cleanup.

Actions run in sequence; one failure does not stop the batch, and failed items are listed in the report for a retry.

Texture atlases (69 formats)

Layout: by size, by name or by group, with padding, edge extrusion, rotation and trimming.

Output: Unity, Godot, Unreal, Cocos2d, Phaser 2/3, PixiJS, Spine, LibGDX, SpriteKit, Starling, Egret, LayaAir, WeChat mini games, plus generic JSON / XML / plist / CSS / CSV.

Validation: POT / NPOT, max size, padding consistency and empty-region checks before export.

Engine data formats (24)

Folder planning for Unity, Unreal, Godot, Cocos and custom templates.

Descriptors are written next to the atlas image, ready to drop into a project.

Custom templates fit in-house engines and internal conventions.

Normal maps and channel packing

Generate normal maps from height maps with adjustable strength and Y-axis convention (OpenGL / DirectX).

Pack roughness, metallic and AO into RGB channels using ORM / RMA conventions instead of manual work.

Configurable channel order for Unity and Unreal habits.

Mipmaps and platform limits

Build power-of-two mip chains with selectable filters and alpha handling.

Built-in size-limit validation for mobile and desktop targets.

Useful when shipping multiple platform builds from one source set.

Asset audits and reports

Scan naming conventions, dimension consistency, duplicates and missing normal/color pairs.

Export CSV / JSON reports for CI gates or art reviews.

Batch evaluation against platform specs such as mobile POT limits.

Available on Microsoft Store

Install directly on Windows 10 / 11 (x64). Chinese and English UI included.
