What it does / 核心能力

One pipeline for game asset production. 一套管线搞定游戏素材生产。

BP

Batch image processing

113 actions: resize, crop, watermark, convert, compress and metadata cleanup in one preset.

批处理图像 — 113 个动作：缩放、裁剪、水印、转换、压缩与元数据清理，一个预设搞定。

AT

Texture atlas packing

69 atlas image formats with padding, extrusion, trimming, rotation and power-of-two checks.

纹理图集打包 — 69 种图集图片格式，支持间距、边缘扩展、裁剪、旋转与 2 的幂校验。

EX

Engine export

24 engine data formats for Unity, Unreal, Godot, Cocos, Phaser, Spine and more.

引擎导出 — 24 种引擎数据格式，覆盖 Unity、Unreal、Godot、Cocos、Phaser、Spine 等。

PT

Game pixel tools

Normal maps, ORM/RMA channel packing, mipmaps, platform size limits and folder planning.

游戏美术工具 — 法线贴图、ORM/RMA 通道打包、mipmap、平台尺寸限制与目录规划。

GC

GUI + CLI, one core

Tune in the GUI, then run the same preset headlessly in scripts and CI.

界面与命令行同一内核 — 在界面中调好参数，再用同一预设在脚本和 CI 中无人值守运行。

PR

Local & private

Runs fully offline — no image uploads, no telemetry, no tracking SDKs. MIT-licensed.

本地与隐私 — 完全离线运行，不上传图片、无遥测、无追踪 SDK。MIT 许可。
